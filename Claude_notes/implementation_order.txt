/*
 * STEP-BY-STEP IMPLEMENTATION GUIDE:
 * 
 * 1. Start with Phase 1 (Helper Functions)
 *    - These are simple, pure functions with no dependencies
 *    - Test each one individually with simple inputs
 *    - Example: is_whitespace(' ') should return 1
 * 
 * 2. Implement Phase 2 (Token Management)
 *    - Basic data structure operations
 *    - Test: create a token, check its values, free it
 * 
 * 3. Build Phase 3 (Lexer Setup)
 *    - Simple initialization and cleanup
 *    - Test: create lexer, check initial values, free it
 * 
 * 4. Add Phase 4 (Parameter Logic)
 *    - Pure logic functions for $ handling
 *    - Test: is_valid_param_start("HOME") should return 1
 * 
 * 5. Implement Phase 5 (String Processing)
 *    - Functions that manipulate strings
 *    - Test: extract_token_value with simple ranges
 * 
 * 6. Build Phase 6 (Decision Functions)
 *    - Logic to determine token properties
 *    - Test: determine_token_type with different inputs
 * 
 * 7. Add Phase 7 (Navigation)
 *    - Functions that move through the input
 *    - Test: skip_whitespace with "   hello"
 * 
 * 8. Implement Phase 8 (State Machine)
 *    - The core logic of your lexer
 *    - Test: set_state with different characters
 * 
 * 9. Build Phase 9 (Token Resolution)
 *    - Brings everything together to create tokens
 *    - Test: resolve simple tokens first
 * 
 * 10. Implement Phase 10 (Main Loop)
 *     - The orchestrator that runs the whole process
 *     - Test: simple inputs like "echo hello"
 * 
 * 11. Create Phase 11 (Public API)
 *     - Clean interface for the rest of your shell
 *     - Test: full integration with complex inputs
 */

/* ============================================================================
 * PROGRESSIVE TESTING INPUTS
 * ============================================================================ */

/*
 * Start with these simple inputs and gradually increase complexity:
 * 
 * LEVEL 1 - Basic Words:
 * - "hello"           -> [hello, EOF]
 * - "hello world"     -> [hello, world, EOF]
 * 
 * LEVEL 2 - Simple Quotes:
 * - "'hello'"         -> [hello, EOF]
 * - "\"hello\""       -> [hello, EOF]
 * 
 * LEVEL 3 - Redirections:
 * - "cat < file"      -> [cat, <, file, EOF]
 * - "cat > file"      -> [cat, >, file, EOF]
 * 
 * LEVEL 4 - Pipes:
 * - "cat | grep"      -> [cat, |, grep, EOF]
 * 
 * LEVEL 5 - Complex:
 * - "echo 'hello world' | cat"
 * - "cat << EOF"
 * - "echo \"$HOME\""
 * 
 * LEVEL 6 - Edge Cases:
 * - "'hello'world"    -> [helloworld, EOF]
 * - "echo\"\""        -> [echo, EOF]
 * - "   echo   "      -> [echo, EOF]
 */
